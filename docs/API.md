# API Documentation

All API endpoints are prefixed with `/api`. Requests (except webhooks and health checks) require authentication via a Bearer token (Clerk JWT) in the `Authorization` header.

## Public / System Endpoints

### Health Check
`GET /health`
Returns the status of the backend API.
- **Auth**: None
- **Response**: `{"status": "healthy"}`

### Clerk Webhook
`POST /api/v1/webhooks/clerk`
Receives user creation/update events from Clerk to sync with the Supabase database.
- **Auth**: Svix Signature Headers

---

## Dashboard Endpoints

### Get Dashboard Overview
`GET /api/dashboard`
Fetches a consolidated view of the user's portfolio, watchlist, recent analyses, and market overview.
- **Auth**: Required
- **Response**:
```json
{
  "portfolio": { ... },
  "watchlist": [ ... ],
  "market_overview": [ ... ],
  "recent_analyses": [ ... ]
}
```

### Get Agent Statuses
`GET /api/dashboard/agents`
Returns the current status of all AI Agents.
- **Auth**: Required

---

## Market Data Endpoints (V1)

### Search Stocks
`GET /api/v1/stocks/search?q={query}`
Searches for assets matching the query.
- **Auth**: Required
- **Response**: Array of matching ticker symbols and names.

### Get Stock Details
`GET /api/v1/stocks/:ticker`
Fetches real-time quotes and basic profile info for a stock.
- **Auth**: Required

---

## AI Committee Endpoints (V1)

### Start Analysis Session
`POST /api/v1/analysis/start`
Triggers the AI Committee to analyze a specific ticker.
- **Auth**: Required
- **Body**:
```json
{
  "ticker": "AAPL"
}
```
- **Response**: Returns the created `session_id`.

### Get Analysis Details
`GET /api/v1/analysis/:id`
Returns the summary and final recommendation of an analysis session.
- **Auth**: Required

### Get Agent Messages
`GET /api/v1/analysis/:id/agents`
Returns the individual analysis messages generated by each AI Agent.
- **Auth**: Required

---

## Watchlist Endpoints

### Add to Watchlist
`POST /api/v1/watchlist`
Adds a ticker to the user's watchlist.
- **Auth**: Required
- **Body**: `{"ticker": "MSFT", "company_name": "Microsoft"}`

### Remove from Watchlist
`DELETE /api/v1/watchlist/:ticker`
Removes a ticker from the user's watchlist.
- **Auth**: Required

## Error Responses
The API uses standardized error responses:
```json
{
  "error": "Message describing the failure."
}
```
Standard HTTP status codes are used (400 for bad requests, 401 for unauthorized, 404 for not found, 500 for internal server errors).
